## 板块

| 类别 | 用途 |
|---|---|
| 💡 **想法 / Ideas** | 你想要 hermes 加什么功能 / 改什么交互 |
| 🐛 **Bug 报告** | 启动失败 / 模型对接错误 / Web UI 卡死 |
| 🛠 **技能开发** | 我做了一个新技能,怎么发布;别人技能我装不上 |
| 💬 **闲聊 / Show & Tell** | 用 hermes 做了什么有趣的事 |
| ❓ **求助** | 怎么配 DeepSeek、怎么改端口、怎么接 ollama |
| 📢 **公告** | 新版本 / 重要变更(只读) |

## 为什么用 GitHub Discussions

- **无需注册新账户** — 你已经有 GitHub 账户了
- **自带 Markdown 渲染、代码高亮、搜索**
- **订阅、@提醒、reaction、accepted answer** 一应俱全
- **零运维**,不用我们维护服务器
- **国内访问稍慢但能开**(GitHub 在国内一般可访问)

国内访问问题可以挂代理,或在微信群里直接讨论。

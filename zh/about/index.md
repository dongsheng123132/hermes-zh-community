# 关于本社区

**U-Hermes 中文社区** 是基于 [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)(MIT 协议)的中文文档与社区入口。

## 我们是谁

由社区志愿者维护。主维护者:

- **dongsheng** ([@dongsheng123132](https://github.com/dongsheng123132)) — `hefangsheng@gmail.com`

希望加入维护团队?发邮件或加微信群说一声。

## 这个社区做什么

1. **提供 hermes-agent 的中文文档**(对仗 [clawd.org.cn](https://clawd.org.cn) 之于 OpenClaw)
2. **聚合中文教程、最佳实践**(怎么接国产模型、怎么走代理、怎么调 prompt)
3. **运营技能市场**(让中文社区贡献的技能能被发现)
4. **承接社区入口**(GitHub Discussions / 微信群 / 知乎话题)

## 这个社区不做什么

- ❌ **不直接销售商业产品** — U 盘成品由 [u-hermes.org](https://u-hermes.org) 卖
- ❌ **不替 NousResearch 官方背书任何决策** — 我们是非官方社区
- ❌ **不审计第三方技能的安全性** — 装"社区"分类技能前自己看代码

## 与上游 / 商业版的关系

```
NousResearch/hermes-agent (MIT, 上游)

```

## 它是什么

**U-Hermes 马盘** 是把开源 hermes-agent 打包成"插上即用"的 Windows U 盘:

- 🦐 内置 **U-Claw**(通用 AI + IM 机器人)+ **U-Hermes**(编程 Agent)双应用
- 💻 双击 U 盘根目录的 `启动 U-Hermes.bat` 即可,**无需安装 Python / Node**
- 🇨🇳 预接 **虾盘云**,首次启动赠送初始 token,DeepSeek / Qwen 等国产模型直连
- 💼 配置 / 历史 / 技能全在 U 盘里,换电脑无感迁移

## 使用流程

1. 收到 U 盘,**插入 Windows 10/11 电脑** USB 口
2. 打开 U 盘,**双击 `启动 U-Hermes.bat`**(或 `U-Hermes.exe`)
3. 启动器自动检测 USB 指纹,关联虾盘云账户
4. 浏览器自动打开 `http://127.0.0.1:8648/` 进入 Web UI
5. 开始对话

## 不想买?用开源版

如果你能折腾 Linux,**完全免费的等价方案**是 [Linux Live USB](/zh/install/linux-live-usb) — 自己制盘、自己配 API Key,功能等价。

## 商业版和开源版的差别

| 维度 | 开源版(免费) | 商业版(¥199 起) |

# 认证技能

由社区核心成员审核过的高质量第三方技能。

<SkillGrid filter="certified" />

## 认证标准

技能要进"认证",需要满足:

1. **有公开仓库**(GitHub / GitLab / Gitee 任一)
2. **MIT / Apache 2 / BSD 等宽松许可**
3. **README 完整**,说明依赖、安装步骤、使用示例
4. **有最近 90 天内的提交活动**
5. **核心成员 code review 通过 + 一次完整功能测试**
6. **没有越权 / 数据回传 / 后门** 等行为

## 申请认证

提 PR 到 [hermes-zh/skills.json](https://github.com/dongsheng123132/hermes-zh)(规划中),并在 PR 描述里附:
- 仓库链接
- 测试视频 / 截图
- 联系方式(微信 / Telegram)

通过后会在本页出现 "认证" 标签。

## 已认证 vs 待认证

如果你的技能在 [社区](/zh/market/community) 列表,正在排队 review,会在 7 天内有反馈。

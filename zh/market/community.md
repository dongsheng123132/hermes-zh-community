## 注意事项

::: danger 安全自负
社区技能未经核心成员审核。装之前最好:
- 看一遍 repo 源码,确认没有上传你的 API Key / 对话历史到外部服务器
- 在沙箱(WSL / 容器 / 虚拟机)里先试一周
- 看 issue 区是否有人反馈过 bug
:::

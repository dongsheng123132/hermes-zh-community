## 升级

```bash
# pip 装的
pip install --upgrade hermes-agent

# Linux Live USB 用户
~/.u-hermes/venv/bin/pip install --upgrade hermes-agent
```

商业版 U 盘出厂后会通过启动器自动检测在线升级。

# 行为守则

我们希望 U-Hermes 中文社区是一个**专业、友善、能学到东西**的地方。

## 鼓励的行为

- 用具体的命令、报错日志、截图沟通问题
- 给新手解释清楚来龙去脉,不嘲讽"这个不是常识吗"
- 分享你踩过的坑、踩坑的解决方案
- 在别人帮你解决后,把答案补到 issue / Discussions,后来人能搜到
- 用 reaction(👍 / ❤️)代替"+1"灌水

## 不被允许的行为

::: danger
- **人身攻击 / 骚扰**:基于性别、种族、国籍、年龄、政治立场等
- **垃圾信息 / 广告**:与 hermes / AI 编程无关的内容
- **泄露他人隐私**:别人的 API Key、对话内容、住址等
- **发布违法内容**:在中国大陆违法的话题
- **窃取他人成果**:抄袭别人的技能 / 教程不署名
:::

## 处理流程

发现违规行为:

1. **轻度**(灌水、答非所问) — 在评论区提醒一下
2. **中度**(吵架、人身攻击) — 私信维护者(微信 `hecare888` / Email `hefangsheng@gmail.com`)
3. **重度**(骚扰、违法、人肉) — 直接 ban,严重的报警

维护者收到举报会在 48 小时内响应。

## 维护者会做什么

- 删除违规帖子 / 评论
- 短期禁言(1 天 / 7 天)
- 永久 ban(GitHub Discussions / 微信群)
- 必要时联系 GitHub / 微信平台举报

## 自我约束

维护者也受同样守则约束。如果你认为维护者做出了不当行为,可以:

- 联系另一位维护者(目前只有 dongsheng,后续会扩充团队)
- 在 GitHub Discussions 公开提出
- 发邮件到 `hefangsheng@gmail.com`
